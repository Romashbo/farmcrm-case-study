# Use cases и критерии приёмки

[К кейсу](../README.md)

## UC-01 — Удалить ферму с переносом животных

**Актор:** владелец аккаунта. **Предусловия:** активная подписка и доступ к ферме.

1. Пользователь запрашивает удаление.
2. Система проверяет наличие животных.
3. При наличии животных пользователь выбирает другую собственную ферму.
4. Система переносит животных, очищает ссылку на прежний загон и удаляет ферму в транзакции.
5. Возвращается результат операции.

Альтернативы: нет животных — удаление без переноса; нет подходящей целевой фермы — отказ; ошибка БД — rollback.

**Given** ферма A с животными и собственная ферма B, **When** удаляю A с переносом в B, **Then** карточки сохраняются, новое местоположение B, прежний загон не указан.

## UC-02 — Завершить напоминание о вакцинации

Предусловие: своё запланированное напоминание.

1. Пользователь подтверждает выполнение.
2. Система проверяет доступ и статус.
3. В транзакции создаёт событие, связанную медицинскую запись и фиксирует выполнение.
4. Возвращает результат.

Альтернативы: запись не найдена, уже обработана либо операция завершается ошибкой.

**Given** pending, **When** подтверждаю выполнение, **Then** создаются связанные записи и статус completed. Последовательное повторение не должно создавать новое событие.

## UC-03 — Списать препарат

1. Пользователь указывает количество.
2. Система блокирует запись остатка, проверяет наличие и допустимость расхода.
3. Обновляет количество и журнал движений в транзакции.

**Given** остаток 10, **When** списываю 3, **Then** остаток 7 и движение расхода на 3. При расходе 11 — отказ без изменения остатка.

## UC-04 — Перейти на платный тариф

1. Пользователь выбирает план.
2. Система создаёт платёж и получает ссылку на оплату.
3. Пользователь оплачивает через провайдера.
4. Система получает и проверяет подтверждение.
5. В транзакции обновляет платёж и подписку.

Альтернативы: неизвестный план, неподтверждённый платёж, потерянное уведомление (синхронизация).

**Given** ожидающий платёж, **When** получено подтверждение, **Then** активирован оплаченный план. Повторное подтверждение не продлевает подписку дважды.

## User stories

- US-01: как владелец хочу найти животное по бирке, чтобы увидеть историю ухода (FR-03).
- US-02: хочу закрыть плановое мероприятие, чтобы связать план и факт (FR-06).
- US-03: хочу видеть остатки и движения препаратов, чтобы контролировать расход (FR-08).
- US-04: хочу повысить лимит карточек, чтобы продолжить учёт при росте хозяйства (FR-10).
