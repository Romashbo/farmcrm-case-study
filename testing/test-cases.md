# Тестовые сценарии

[К кейсу](../README.md)

Статус всех тестов: **не выполнены**. Использовать отдельное тестовое окружение и синтетические данные.

| ID | Приоритет | Действие | Ожидаемый результат |
| --- | --- | --- | --- |
| TC-01 | P1 | Повторно создать карточку с той же биркой | Отказ, одна карточка |
| TC-02 | P1 | Создать карточку сверх тарифного лимита | Отказ, лимит сохранён |
| TC-03 | P0 | Проверить изоляцию двух тестовых аккаунтов | Нет доступа к чужим данным |
| TC-04 | P1 | Удалить ферму с животными без переноса | Отказ |
| TC-05 | P1 | Удалить ферму с переносом в другую свою | Карточки сохранены, прежний загон сброшен |
| TC-06 | P1 | Завершить запланированную вакцинацию | Событие, медзапись, completed |
| TC-07 | P1 | Повторить завершение последовательно | Отказ, нет нового события |
| TC-08 | P1 | Остаток 10, списание 11 | Отказ, остаток 10 |
| TC-09 | P0 | Остаток 10, два параллельных расхода по 7 | Один успех, остаток 3 |
| TC-10 | P0 | Повторное подтверждение одного платежа | Подписка обновлена только один раз |
| TC-11 | P0 | Истёкшая подписка | Доступ согласно тарифной политике |
| TC-12 | P1 | Создать продажу продукции без покупателя | Ошибка валидации |
| TC-13 | P1 | Проверить защищённую операцию без подтверждения | Отказ |

Проверять HTTP-ответ и итоговое состояние данных. Конкурентные сценарии выполнять с синхронизированным стартом. Платежи тестировать только на тестовом контуре.
